# Questions-clés

Questions posées à l'identique à tous les candidats. Elles sont formulées de façon neutre
et servent de lignes aux matrices comparatives.

## Valeurs de position autorisées

| valeur           | Sens                                                        |
|------------------|-------------------------------------------------------------|
| pour             | Le candidat soutient la mesure ou l'orientation              |
| contre           | Le candidat s'y oppose                                       |
| nuancé           | Position intermédiaire ou conditionnelle (préciser en détail) |
| pas de position  | Aucune prise de position publique trouvée                    |
| ambigu           | Déclarations contradictoires ou trop floues pour trancher     |

Pour les questions à réponse ouverte (ex. un âge, un montant), la colonne `position`
contient la valeur annoncée et la colonne `détail` les conditions.

## Ajouter une question
- Choisir un id `Q-<theme>-<mot>` jamais utilisé.
- La formuler de façon neutre, sans présupposer de réponse.
- La renseigner ensuite pour **tous** les candidats (à défaut : `pas de position`).
